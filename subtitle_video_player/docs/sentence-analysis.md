# 句子解析

## 使用

1. 在字幕中选择一个词、词组或整句，点“析句”。
2. 回答卡片先展示实际解析原文，收到完整标注后显示结构和译文。
3. 悬浮查看成分、词形、难点和关系箭头；点击可固定，再次点击、点击卡片空白处或 Esc 可退出。触屏通过点按使用；Tab 可依次聚焦标注。
4. “只看主干”折叠从句和修饰语；“断句”显示单／双斜线，两者可以同时开启。折叠标签仍支持关系提示。
5. 展开“调整范围”可添加相邻字幕、裁剪文本或恢复本次原文。重新解析会追加一组问答，保留此前结果。
6. 可在原聊天输入框继续追问，后端保留本轮原句和解析数据。朗读优先美式英语，朗读前暂停视频，结束后由用户继续播放。

核心布局、SVG 和交互处理适配自陪读蛙 1.52.1 的长难句面板，沿用原版的标注语法约束。模块通过原生 DOM 在播放器内独立运行，来源和许可证见 [布局来源](readfrog-layout-attribution.md)。

原句不叠加选区点线。圈线使用原版 SVG 和背景图；小标签使用原版行内锚点，保留字体、行高、间距及嵌套样式。重复的同起点或同一短语内部同名标签只显示一次，其完整说明仍可悬浮查看。浮层沿用原版的上下位置选择、宽度限制和坐标取整，覆盖现有内容，不预留额外高度。箭头沿用原版的贝塞尔曲线及箭头尖计算。

小标签按显示语义着色：词形使用低饱和石板灰，时间／原因／条件等语义关系使用灰紫，难点继承所在谓语、从句等成分的颜色。深色主题使用对应的浅灰与浅紫；字号、锚点、行高和布局保持不变。

## 范围与资料边界

- 自动扩展最多向前、向后各两条字幕；遇到完整句末、明显的说话人标记或超过 2.5 秒的间隔时停止。再根据选区定位所在句子，保留跨句的显式选区。
- 合并字幕空白，保留拼写和标点。原选区保留在问答引用中；重复词通过选区位置定位。
- 句子范围始终显示。自动补齐属于启发式处理，无法保证识别所有口语省略、说话人变化、缩写或双语字幕；用户可手动调整。
- 标注只对应当前显示的原文。补词／语序还原放在提示中，疑点、字幕错误和多解放在说明区。有歧义的片段必须标 `uncertain: true`，并在该片段的 `note` 说明不同读法，悬浮显示“关系待确认”，不画确定箭头。
- 每次最多 4,000 字符、160 项标注，嵌套最多 13 层。超长选择提示缩小范围。已更换字幕时，旧卡片不再向新字幕取相邻内容或重新发起分析。

## 请求与渲染

沿用 `/stream`、`preserve: true`、当前会话 ID、服务商与模型，以及原有系统语境。仅本轮 user_message 指定 JSON 格式，普通追问仍走原 Markdown 回答流程；无需服务端新增接口或模型原生 JSON Schema 参数。

响应对象：

```json
{
  "annotations": [
    {"text":"The files sent yesterday","type":"subject"},
    {"text":"sent yesterday","type":"attributive","form":"past-participle","head":"files","uncertain":false,"restore":"that were sent yesterday"},
    {"text":"need","type":"predicate"},
    {"text":"revision","type":"object"}
  ],
  "translation":"昨天发出的那些文件需要修改。",
  "issues":[]
}
```

原文由客户端保存，不从响应重建。`type` 表示句中作用，`form` 表示结构形式，`sense` 表示时间／原因／条件等关系，`obstacle` 表示倒装／省略／被动等难点；可选 `note`、`tense`、`restore`、`uncertain` 提供说明。重复的 `text` 和 `head` 必须分别指定从 1 开始的 `occurrence` 和 `headOccurrence`。

提示词包含七组完整 JSON 示例：陪读蛙的嵌套从句、非谓语、倒装／省略三组示例，以及省略条件状从、疑问句拆分谓语、非谓语宾语与同位语从句、修饰关系歧义四组补充示例。另要求明确填写可确定的 `sense`／`obstacle`，保留非谓语短语内部的核心成分，并在省略还原中使用明确的原文先行词。

补充规则覆盖比较结构与主动否定、被动与否定的字段优先级、重复功能词的 `occurrence`、共享先行词不得递增 `headOccurrence`，以及强调句禁止与定语从句混合标注。

标注允许嵌套，不允许交叉、相同范围重复或虚构原文。无法精确对应的标注或关联被忽略并提示；全部失效或 JSON 格式错误则允许重试。模型文字均通过 DOM 文本节点显示，不执行模型生成的 HTML、脚本或样式。生成中保留原句与占位，完成后一次性校验标注，避免半截 JSON 显示到聊天里。停止、网络中断和格式错误均保留范围调整入口。

带 `head` 的标注必须显式返回布尔值 `uncertain`。只有 `uncertain: false` 且 `head` 可准确定位时才显示关系箭头；`uncertain: true`、字段缺失或类型错误均不显示确定箭头。缺失／类型错误时悬浮显示“尚未确认这处关系，暂不显示箭头。”，这是新输出的容错规则，不提供旧结果兼容层。模型已明确判断为确定但实际判断错误的情况，仍需通过语法质量验收发现。

主语与谓语等关系不会自动猜连。箭头与浮层随句子换行和窗口尺寸更新。默认浅色；宿主显式使用 `.dark` 或 `data-theme="dark"` 时采用深色配色。系统减少动态效果偏好会关闭动画。

## 文件与构建

- `js/sentence_analysis.js`：取句、提示词、标注校验、交互面板与整句朗读。
- `assets/sentence_analysis.css`：作用域内样式及动画。
- `subtitle_video_player.html`：入口与现有发送／重试／停止／会话生命周期集成。
- `scripts/build_single-html.js`：把模块和样式内嵌到单文件版。
- `test/fixtures/sentence_analysis_acceptance.js`：十五条真实模型验收句、关键结构要求、禁止结构及合法粒度分支。
- `scripts/test_sentence_analysis_live.js`：逐句执行真实请求，检查关键字段、原文映射、首句卡片／窄屏／普通追问，并保存报告。

```powershell
pnpm test
pnpm run build:single-html
# 指向已有 Playwright 包目录；本测试不下载浏览器、不调用真实 AI。
$env:SVP_PLAYWRIGHT = '已有 Playwright 包的绝对路径'
pnpm run test:sentence:browser
pnpm run test:sentence:layout
# 同一示例的原版快照对照；还需已有 pngjs 包。
pnpm run test:sentence:reference
```

浏览器检查使用本机 Chrome 和隔离页面，模拟 `/models`、`/stream` 与朗读引擎；临时目录、截图和报告均位于项目的 `test-results/sentence-analysis/`，临时浏览器数据在结束后清理。覆盖普通版和单文件版的取句、原文保留、箭头、嵌套高亮、固定／退出、键盘、触屏、深色主题、主干／断句、390px 布局、追问、调整范围、错误重试、停止、文本安全及新对话清理。

语义配色检查覆盖词形、语义关系和难点三类标签的浅色计算颜色、深色计算颜色，以及从句难点对从句绿色的继承。

原版对照使用 `test/fixtures/readfrog-1.52.1.json` 的同一份示例和 `readfrog-interaction.js` 中提取的交互逻辑，仅用于测试。两种宽度、两种主题、八种状态共32场景，对比核心面板区域尺寸、文字坐标与换行、箭头路径以及截图像素。播放器外围标题、字幕跳转、范围调整和异常提示不参与核心区域像素比较。截图和报告在 `test-results/sentence-analysis-reference/`。测试不会在播放器中引入参考扩展或其运行时。

原版像素对照会把播放器的小标签统一为旧版中性色，专测布局、文字坐标和 SVG；扩展语义色板由上述普通版与单文件版浏览器回归单独验证。

实际模型的语法判断和遵循输出格式的质量取决于所选模型；模拟验证不能替代真实模型验收。朗读音色与声音仍需在目标设备实际试听。

真实句集逐条检查必需的 `text`、`type` 及适用的 `form`、`sense`、`obstacle`、`head`、还原内容；出现标注映射丢弃或 `forbidden` 禁止结构即失败。检查允许有依据的粒度差异，例如名词可单独作宾语，也可与其同位语从句整体作宾语，但内部从句和关系仍必须完整。当前十五句严格覆盖全部 8 种 `type`、5 种 `form`、9 种 `sense` 和 13 种 `obstacle`。
