# 请求队列

播放器每次执行一项请求。忙碌时提交的普通问答（含划词快捷输入提问）、查词、析句、重新解析和历史重试进入同一待发送队列，按顺序独立执行；每项沿用当前会话 ID 和 `preserve: true`，不合并问题或中途注入当前回复。

## 操作

- 划词后，快捷输入框与下方菜单同时显示。鼠标松开后，快捷输入框自动聚焦并保留字幕引用，可以直接打字。按 Ctrl+C 复制字幕选区原文。输入框里选中部分文字时，复制框内所选文字。支持 CSS 文字高亮时，气泡获得焦点会用淡黄色标出原字幕里的引用范围，关闭气泡时清除。输入框以 18px 模糊后方内容，未聚焦且鼠标未悬停在快捷输入框或“问AI”上时为半透明；快捷输入与菜单共用一个颜色固定的外框和整体阴影，内部没有视觉间隙或独立接合阴影；菜单保持原有背景与不透明状态，快捷输入的渐变在接合处匹配菜单颜色；悬停快捷输入框或“问AI”时变为不透明，内部聚焦时不受鼠标移开影响，失焦且未悬停后恢复半透明，过渡时间为 160ms。
- 输入框空闲时显示“发送”，执行中或有待发送项时显示“排队”。Enter 提交，Shift+Enter 换行，中文输入法确认期间的 Enter 不提交。
- 红色方形按钮停止当前回复并暂停队列。已有输入草稿或引用时，停止不会用旧问题覆盖它们。
- Esc 可收起 AI 窗口并保留草稿和队列，生成继续执行；编辑器及解析提示先处理各自的 Esc，不会同时收起窗口。
- 队列位于输入框上方，仅显示尚未开始的项目，带序号、类型、内容摘要和提交时间点。列表可折叠，有高度上限并在内部滚动；AI 按钮旁显示待发送数量。
- AI 窗口的聊天表头、设置面板、排队区、引用条和输入行按内容取高，只有消息区领取剩余空间并滚动。浮窗以操作区域所需高度作为下限，缩小到下限后保留完整输入区，拉大浮窗可增加回复空间。排队表头保持完整，长回复不会压缩排队操作区；收起 AI 窗口时同步收起设置区域，重新打开窗口后默认不展开设置。
- 内容撑高使浮窗越过屏幕下沿时，在视口能容纳操作区的情况下临时上移。窗口记忆保留用户选择的尺寸和位置；关闭设置或队列缩减后恢复，手动拖动、缩放后的新选择仍正常保存。
- 编辑在列表中展开，普通问答修改正文，查词修改目标词／词组，析句修改实际解析原文；原有引用和提交位置保留。保存／取消编辑均保留原队列位置；Ctrl+Enter 保存，Esc 取消编辑。
- 编辑中的项目排到时等待操作完成，不跳过它；前面的项目仍可正常执行。重新排序、取消及清空只影响等待项目，清空不会停止正在执行的请求。
- 编辑排队中的历史重试会作为一条新问题发送，保留原失败消息及其重试入口，避免旧聊天问题与新回复内容不一致。

## 暂停与恢复

- 请求失败后，剩余项目保留并暂停。重试本次失败项成功后恢复队列；重试其他历史消息排在队尾，不能解除本次失败造成的暂停。也可点击“继续”跳过失败项，执行下一项。
- 主动停止后保留剩余项目，只有“继续”会恢复。暂停期间新提交仍进入队尾。
- 没有剩余项目时，失败／停止不阻挡之后的新提交。
- 新对话、加载视频或字幕会取消旧请求、清空等待项目，并生成新的会话 ID。换视频、换字幕或重建字幕列表时，清除旧划词选区、高亮和快捷草稿。执行标识防止迟到的旧响应修改新会话状态。正常播放、暂停及跳转不清理队列。
- 队列只保存在当前页面内存中，不恢复刷新前的请求或待发送内容。

## 语境与通知

提交时保存系统语境、播放位置、问题、引用、模型路由及选区原文。排队期间继续观看或修改设置不会改变已提交项目；前序成功回复依次保留在同一后端会话中。查词本地 COCA 数据准备仍属于该项执行周期，取消和失败沿用原处理方式。

队列自动执行下一项本身不主动跳转或暂停视频。后台请求开启且窗口收起时，划词“查词”“析句”和快捷输入提问会直接入队、保持窗口关闭；进入等待队列时提示请求摘要、已提交状态、前序请求状态及队列位置。快捷输入提问与普通问答共用同一队列，直接点击“问AI”仍只打开窗口并填入引用。窗口收起时每项完成也有独立通知，包含对应内容摘要，下一项的生成通知不覆盖它。完成通知可点击打开 AI 对话；后台请求开启、自动展开关闭时，点击成功完成通知会先暂停正片，再打开窗口，鼠标和键盘激活规则一致。开启“后台请求”右侧的“完成后自动打开 AI 对话窗口”时，请求成功完成后若正片仍在播放则先暂停，随后自动展开窗口并保留输入焦点；已经暂停则直接展开，不重复暂停。失败和停止不会自动展开或暂停，点击它们的通知仍可打开窗口但不暂停；后台请求关闭时的普通成功通知点击也不暂停。该选项默认关闭，关闭后台请求会同时取消自动打开。打开窗口撤销这些 AI 通知，原有操作提示与其他 toast 的实现保持不变。

## 实现与验证

- `js/ai_request_queue.js`：独立队列状态、暂停恢复、编辑阻塞及过期执行标识。
- `subtitle_video_player.html`：语境快照、请求生命周期、队列界面及内容切换入口。
- `assets/ai_queue.css`：队列和独立停止按钮的作用域样式。
- `test/ai_request_queue.test.js`：队列状态及顺序、恢复、编辑、重置竞态检查。
- `scripts/test_ai_queue_browser.js`：隔离 Chrome，模拟 `/models` 和 `/stream`，检查普通版和单文件版的实际 UI、请求参数与串行执行。

```powershell
pnpm test
pnpm run build:single-html
$env:SVP_PLAYWRIGHT = '已有 Playwright 包的绝对路径'
pnpm run test:queue:browser
pnpm run test:sentence:browser
```

测试不下载浏览器或调用真实 AI，临时文件和报告位于项目内的 `test-results/ai-queue/`。模拟会话历史只用于验证前端顺序和会话 ID，不替代后端的历史保存契约。
