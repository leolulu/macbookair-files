# 查词发音

## 范围与交互

- 使用浏览器 `speechSynthesis`，不嵌入模型、音频词库或第三方 SDK，不增加 AI 请求。
- 在原有一次查词提示词中约定：首次介绍核心英语单词/短语时用普通 Markdown 加粗。消毒后的回答由独立模块 `js/lookup_speech.js` 添加按钮；无专用内部标记。
- 按钮只出现在查词回答中，与 COCA 候选、词形还原或收录情况无关。读显示词形，例如 `went` 就读 `went`。
- 当前识别纯英文字母、词内撇号/连字符及空格组成的短词组，最多 6 个词、80 个字符。忽略中文、数字、混合说明、链接、标题、代码和重复词。未按约定加粗时不添加按钮；不从普通文本猜核心词。
- 优先 en-US（含 en_US），其次其他英语音色；同类音色优先设备标为默认的音色。不指定平台专属名称，也不保证离线。
- 首次声音列表为空时在点击事件中直接用 en-US 请求朗读，同时监听 voiceschanged。接口不存在时保留解释正文；缺少英语音色或发音失败时提示，可再次点击重试。
- 点击朗读会暂停当前视频；不会自动恢复。连续点击停止上一段朗读。关闭对话窗、开启新对话、切换到后台或离开页面时停止朗读。

## 渲染与样式

按钮由本地代码在 Markdown 消毒后创建，用 WeakMap 关联朗读词形；AI 提供的 HTML 不能直接创建可执行发音按钮。事件委托与朗读状态不依赖临时 DOM 节点，流式重绘后重新装饰并恢复按钮状态及键盘焦点。

单色 SVG 随正文字号缩放，图标 1em，高度在既有 1.55 行高以内。透明点击区域向外扩展 3px，不参与排版。按钮没有文字内容，SVG 使用 inline 显示，避免 innerText 额外产生换行。按钮占少量水平空间，行尾空间不足时仍按正文正常换行。

## 验证记录（2026-09-07）

- `pnpm.cmd test`：49 项通过，涵盖英语筛选、美国/其他英语音色回退、异步音色、连续点击、过期回调、引擎错误/超时、后台取消及不支持接口。
- `pnpm.cmd run build:single-html` 通过；普通 HTML 2 段、single HTML 15 段内联脚本语法检查通过。
- Chrome MCP 使用已配置模型：普通版实际查 `running costs`，single 版实际查 `Quidditch`，各一次 AI 请求生成可点击回答。
- 两个版本通过真实系统朗读的 start/end 事件验证，使用 Microsoft Mark / en-US。此处验证的是引擎完成事件，未对声音进行人工听辨。
- 用户随后在 Windows Chrome 中实际试听，确认发音效果良好。
- 真实连续点击验证上一段收到 interrupted，下一段正常结束；发音没有增加查词网络请求。
- 普通版用真实播放的 canvas 视频流验证点击后 video.paused 从 false 变为 true。
- 可控 SSE 验证 COCA 加载失败仍能为 went 和短语添加按钮，流式未闭合强调不误生成按钮，完成后添加，停止/错误/重试可用；普通追问不添加按钮。引擎故障另用注入错误验证按钮复位。
- 两个版本比较有/无按钮的浏览器选区文字与 innerText，均一致。260/360px 容器下，14/18/22px 字号的单行样本添加按钮后高度差均为 0；长句可以因按钮占宽而正常换行。

Mac、iPhone/iPad、Android 的真实设备朗读与触摸体验尚待验证。当前不提供按语境指定音素或词典读音的能力，同形异音词由设备朗读引擎处理。
