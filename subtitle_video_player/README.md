# subtitle_video_player

本项目是支持多种字幕格式、字幕选词和 AI 问答的本地视频播放器。开发时使用 `pnpm test` 运行测试，使用 `pnpm run build:single-html` 生成单文件版本。

## 播放进度云端保存

播放器通过 Firebase Realtime Database 按视频保存播放位置：本地文件使用文件名、大小和修改时间作为身份；在线视频仅使用 URL 路径（含文件名），忽略协议、域名或 IP、端口、查询参数及片段，同一路径共用进度。直接输入 URL 与 Dufs 文件列表采用同一规则，路径保留大小写，中文按标准 URL 路径编码处理。标识经 SHA-256 映射为固定路径，每个视频独立读写，计算出的地址会缓存复用。播放过程中每 30 秒保存一次，暂停、拖动结束、播放结束及页面隐藏或关闭时补存。普通保存至少间隔 10 秒，等待期间只保留每个视频的最新进度；隐藏或关闭页面时跳过间隔等待，仍沿用同一串行队列，重复位置会合并。所有保存请求使用 keepalive；若离开时已有请求在途，最新位置会排在它之后尽力补存，允许保留最近成功保存的位置。读写请求均在 10 秒后超时；保存失败保留最新进度供后续保存重试，其他视频的待存记录可继续处理。保存和失败处理均在后台完成，不弹操作提示。

重新打开已有记录的视频时，视频区域正中间会显示上次播放时间；点击“跳转”才恢复，点击“不跳转”或 Escape 从当前位置正常记录。直接播放、拖动进度或点击字幕跳转也会关闭提示并开始记录；用户操作后忽略迟到的恢复提示。尚未操作时保留旧记录，恢复跳转本身不会触发重复保存，快速切换视频时忽略迟到响应。

视频编号统一使用本地内置的 [js-sha256 1.0.0](https://github.com/emn178/js-sha256/tree/v1.0.0)（MIT 许可）计算，生成 64 个十六进制字符的记录键名。编号计算不依赖 `crypto.subtle`，适用于本地文件、HTTP 和 HTTPS 页面；浏览器脚本与许可证位于 `assets/vendor/js-sha256/`，单文件版一并内联，无需额外联网加载。

在线视频改为仅按 URL 路径标识后，旧版按完整 URL 生成的记录仍保留在云端，不自动迁移；本地文件的身份与记录不变。

数据库地址在 `subtitle_video_player.html` 的 `firebaseProgressClient` 中固定配置，修改后需运行 `pnpm run build:single-html` 同步单文件版。数据库位于新加坡（asia-southeast1），`progress` 路径按功能需要允许匿名读写，因此该 URL 同时具有读写权限，不应公开给不受信任的用户。Firebase 官方限制包括每秒 1000 次写入、Spark 免费计划 1 GB 存储和每月 10 GB 下载，适合高频进度保存；云端不可用时不影响本地播放。

## 后台请求

AI 对话窗口支持按 Esc 收起，效果与右上角收起按钮一致，保留输入草稿、请求队列和后台生成。队列编辑、句子解析提示及欧路确认框优先处理 Esc；输入法组词、原生下拉框和全屏退出不触发窗口收起，同一次按键不会连带关闭下层提示。

AI 对话设置中的“后台请求”默认不勾选，选择会保存在本地。开启后，窗口关闭时点击划词菜单的“查词”或“析句”会直接请求并保持窗口关闭，沿用按钮闪烁及成功／失败标记；窗口已经打开时继续在当前窗口请求。其右侧同一行显示“完成后自动打开 AI 对话窗口”，默认关闭，选择同样保存在本地；开启后，收起窗口中的请求成功完成时自动展开，保留当前输入焦点，失败和主动停止仍只提示。关闭“后台请求”时，同时取消自动打开，二级选项保留位置并置灰禁用；再开启后台请求时，需重新勾选自动打开。“问AI”、窗口内重新解析和重试均沿用原有行为，同时只能执行一个请求。

AI 窗口收起时，生成中、成功、失败和主动停止会通过 toast 提示，原有闪烁、绿点和红点继续保留。每轮生成中最多提示一次，约 2.6 秒后消失；每条请求完成时单独提示对应内容，下一条生成不会覆盖完成通知。完成通知扩大了点击区域并显示“点击查看 AI 对话”，整块支持点击或键盘激活；停留约 6 秒，鼠标悬停或键盘聚焦时暂停消失计时。打开窗口会撤销 AI 状态通知并清除未读标记；开启自动展开时，成功后直接显示窗口。窗口打开时不弹此类通知，原有操作提示和其他 toast 沿用现状；空回复保持原有判定，开启新对话取消的旧请求不追加结束通知。

## 请求排队

当前回复生成时，输入框仍可用 Enter 或“排队”提交下一条，Shift+Enter 换行；独立的停止按钮用于停止当前回复。查词、析句、重新解析和重试共用同一个串行队列，待发送内容位于输入框上方，支持折叠、编辑、取消、上移、下移和清空。尚未发送的项目不会提前进入聊天记录。

每项保留提交时的播放位置、引用字幕、解析原文、设置及作品语境，前序回复依次进入同一会话。主动停止会暂停剩余队列并保护输入草稿，需点击“继续”；失败后保留队列，重试该失败项成功后自动继续。编辑中的项目排到时等待保存或取消编辑。新对话、换视频或字幕会取消旧请求并清理队列；收起窗口继续执行，刷新页面不恢复队列。操作规则与验证入口见 [请求队列说明](docs/ai-queue.md)。

## 查词中的 COCA 排名

查词首次使用时解压本地词表，只把选中内容相关的单词、词性、排名候选附加到原有一次 AI 请求。AI 根据句意选择候选，播放器将引用替换为真实排名括注。支持规则词形和一步明确词族参考；不进行不规则过去式/过去分词还原或拼写相似度匹配。无法确定时省略排名，数据不可用时继续原有查词。

普通 HTML 与 single HTML 均可直接打开，使用同一份内嵌 gzip 数据，无额外词频服务。数据来源、压缩格式、体积和验证方法见 [COCA 数据说明](docs/coca-rank.md)。

## 查词发音

查词回答中由 AI 明确标记的目标英语单词和短语旁会出现小喇叭，普通加粗不触发发音按钮。点击调用浏览器朗读，优先美式英语音色，缺少时使用其他英语音色。连续点击会替换上一段朗读；发音前暂停视频，听完由用户继续播放。无需语音模型、额外 AI 请求或语音服务密钥，也不依赖 COCA 收录范围。普通版和 single HTML 使用同一模块。

音色和联网需求由设备及浏览器提供的语音服务决定；当前只对 Windows Chrome 做了实际朗读验证，其他设备需实测。实现约定和验证记录见 [查词发音说明](docs/lookup-speech.md)。

## 查词单词视频

每条查词回答下方会独立查询百度翻译的单词视频，有结果时显示封面、词条和时长，点击后原位播放。视频采用 CDN 直链，点击前只加载封面。原词无视频时，先尝试本地 COCA 提供的唯一规则原形；仍无结果再单独请求 AI 生成最多三个词形候选，按顺序查询并在首次命中时停止，附件标注“相关词形”。正常无视频时隐藏附件，查询失败仅在附件内提供重试。

候选请求沿用该次查词提交时的后端、服务商和模型，使用专用会话与 `preserve:false`，只发送选中词和所在句子。原查词提示词、会话历史、请求队列及完成通知保持原有行为；视频慢或失败均不阻塞文字回答。只对不超过 80 字符、最多六词的英文单词或短语启用附件。

播放讲解视频会暂停正片及朗读；开始朗读或继续播放正片会暂停讲解视频。收起 AI 窗口或切换标签页只暂停播放，后台查询继续；停止当前回复会取消该卡片尚未完成的视频查询。新对话、切换视频或字幕会取消旧查询并暂停讲解，保留的历史视频仍可手动播放。普通版和单文件版使用同一实现。

视频素材存在横竖屏及编码差异，播放器保持比例；仅能解码音频时保留封面并提示。实现、缓存和验证入口见 [单词视频说明](docs/word-video.md)。

## 欧路笔记格式约定

播放器生成的欧路 Note 以 `**来源：**《` 作为稳定前缀，欧路中保留完整来源；`eudic_auto_vocabulary_task_system` 据此识别播放器 Note，并在生成滴答正文时隐藏来源行、保留引用块，统一显示“生词语境”标题。修改此前缀或后端识别规则时，需要同步检查两个项目。

## 句子解析

划选字幕后点“析句”，在现有 AI 对话中生成交互解析卡片。支持成分与嵌套从句标注、悬浮关系箭头、点击固定／Esc 退出、主干折叠、断句、译文和整句朗读。选中词或词组时会尝试补齐所在句子；卡片内可调整范围并重新解析，原始选区保留在问答引用中。

AI 返回结构化标注，播放器校验后绘制；生成时显示原句与占位状态，格式异常提供重试。沿用现有服务商、模型、字幕语境和会话记忆。普通版与单文件版使用同一模块。范围规则、数据约定和验证方式见 [句子解析说明](docs/sentence-analysis.md)。

核心布局、SVG 和交互处理适配自陪读蛙 1.52.1，以原生 DOM 实现；来源与 GPL-3.0 许可证说明见 [布局来源](docs/readfrog-layout-attribution.md)。
