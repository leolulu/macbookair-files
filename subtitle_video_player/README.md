# subtitle_video_player

本项目是支持多种字幕格式、字幕选词和 AI 问答的本地视频播放器。开发时使用 `pnpm test` 运行测试，使用 `pnpm run build:single-html` 生成单文件版本。

## 后台请求

AI 对话设置中的“后台请求”默认不勾选，选择会保存在本地。开启后，窗口关闭时点击划词菜单的“查词”或“析句”会直接请求并保持窗口关闭，沿用按钮闪烁及成功／失败标记；窗口已经打开时继续在当前窗口请求。“问AI”、窗口内重新解析和重试均沿用原有行为，同时只能执行一个请求。

## 查词中的 COCA 排名

查词首次使用时解压本地词表，只把选中内容相关的单词、词性、排名候选附加到原有一次 AI 请求。AI 根据句意选择候选，播放器将引用替换为真实排名括注。支持规则词形和一步明确词族参考；不进行不规则过去式/过去分词还原或拼写相似度匹配。无法确定时省略排名，数据不可用时继续原有查词。

普通 HTML 与 single HTML 均可直接打开，使用同一份内嵌 gzip 数据，无额外词频服务。数据来源、压缩格式、体积和验证方法见 [COCA 数据说明](docs/coca-rank.md)。

## 查词发音

查词回答中由 AI 明确标记的目标英语单词和短语旁会出现小喇叭，普通加粗不触发发音按钮。点击调用浏览器朗读，优先美式英语音色，缺少时使用其他英语音色。连续点击会替换上一段朗读；发音前暂停视频，听完由用户继续播放。无需语音模型、额外 AI 请求或语音服务密钥，也不依赖 COCA 收录范围。普通版和 single HTML 使用同一模块。

音色和联网需求由设备及浏览器提供的语音服务决定；当前只对 Windows Chrome 做了实际朗读验证，其他设备需实测。实现约定和验证记录见 [查词发音说明](docs/lookup-speech.md)。

## 欧路笔记格式约定

播放器生成的欧路 Note 以 `**来源：**《` 作为稳定前缀，欧路中保留完整来源；`eudic_auto_vocabulary_task_system` 据此识别播放器 Note，并在生成滴答正文时隐藏来源行、保留引用块，统一显示“生词语境”标题。修改此前缀或后端识别规则时，需要同步检查两个项目。

## 句子解析

划选字幕后点“析句”，在现有 AI 对话中生成交互解析卡片。支持成分与嵌套从句标注、悬浮关系箭头、点击固定／Esc 退出、主干折叠、断句、译文和整句朗读。选中词或词组时会尝试补齐所在句子；卡片内可调整范围并重新解析，原始选区保留在问答引用中。

AI 返回结构化标注，播放器校验后绘制；生成时显示原句与占位状态，格式异常提供重试。沿用现有服务商、模型、字幕语境和会话记忆。普通版与单文件版使用同一模块。范围规则、数据约定和验证方式见 [句子解析说明](docs/sentence-analysis.md)。

核心布局、SVG 和交互处理适配自陪读蛙 1.52.1，以原生 DOM 实现；来源与 GPL-3.0 许可证说明见 [布局来源](docs/readfrog-layout-attribution.md)。
